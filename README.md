# Nexo Travel IA

Prototipo web de una aplicación de viajes con:

- Buscador de destinos.
- Fichas con fotos, presupuesto, clima y recomendaciones.
- Alertas de vuelos baratos guardadas en el dispositivo.
- Buscador de destinos según presupuesto.
- Modo aeropuerto.
- Plan Gratis y Premium.
- Diseño adaptable a celular y computadora.
- Preparación como PWA.

## Importante

Los precios y vuelos actuales son datos de demostración. La próxima etapa es conectar servicios reales de vuelos, clima, mapas, hoteles y usuarios.
